**Cellulose-Builder** is a toolkit for generating crystalline cellulose structures
ready for molecular dynamics simulations.

## Features

- Generates all major cellulose allomorphs (Iα, Iβ, II, III)
- Compatible with GROMACS, NAMD, AMBER
- Customizable microfibril dimensions
- Outputs standard PDB and topology files
